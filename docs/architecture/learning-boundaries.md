# 学习边界

本项目的学习重点不是一次性写出完整电商系统，而是在每次迭代中观察设计为什么发生变化。

每个阶段只引入当前问题需要的能力：

1. 订单领域：错误、状态变化、领域规则。
2. HTTP 接入：协议层与业务层的分离。
3. 数据库：SQL、事务、连接池和持久化边界。
4. 并发库存：锁、隔离级别、幂等和一致性。
5. 认证授权：身份、权限和安全边界。
6. 缓存：读取性能与数据一致性。
7. 消息：异步处理、重试、重复消费和最终一致性。
8. 可观测性：日志、指标、Trace 和故障定位。
9. 部署：配置、健康检查、优雅关闭和发布。

每个阶段的代码由学习者完成。助手只提供需求、结构、示例、注释、排错和设计复盘。
